## Что произошло хронологически

1. В 08:45 UTC по расписанию запустился workflow `Autonomous AI Localization & OTA Dispatch` (run `42190000847`).
2. Модуль `auto_translate.js` взял накопившуюся очередь из 289 строк и отправил запросы к Gemini API.
3. В функции `callGemini()` чтение ответа велось через `res.on('data', chunk => data += chunk)`.
4. Во 2-м батче (139 строк, ~15 КБ русского текста) сетевой буфер TCP разрезал двухбайтовые символы кириллицы на границе пакетов.
5. При приведении к строке `data += chunk` неполные байты превратились в символы `\uFFFD` в 3 терминах (`Grep aar-log.md...`, `Wait and check...`, `Query live UI...`).
6. `auto_translate.js` передал строки в `npm run merge`.
7. `merge_translations.js` запустил валидацию `npm test`.
8. Тест `testDictionaryIntegrity` обнаружил `\uFFFD`, заблокировал слияние и завершился с кодом 1, предотвратив коммит битых строк в `main`.
9. Пользователь получил уведомление о сбое ночного джоба в GitHub Actions.

## Исправления

1. **Буферизованное декодирование в `localization/auto_translate.js`**:
   - Чанки аккумулируются в массив буферов `chunks.push(chunk)`.
   - Декодирование в строку UTF-8 выполняется однократно после получения полного ответа: `Buffer.concat(chunks).toString('utf8')`.
   - Внедрена очистка спарсенного JSON от любых символов `\uFFFD` перед передачей в слияние.
2. **Многоуровневая защита в `localization/merge_translations.js`**:
   - `isInvalidKey(k, v)` отбрасывает любые ключи и значения, содержащие `\uFFFD`.
   - Добавлен автоматический откат (`fs.writeFileSync(dictPath, originalDictContent)`) при сбое валидационных тестов.
3. **Фильтрация в OTA Updater (`bin/updater.js`)**:
   - В `mergeDictionaries()` добавлен фильтр, удаляющий `\uFFFD` при слиянии словарей.
4. **Юнит-тест расщепления чанков (`test/queue_sync_integrity.test.js`)**:
   - Добавлен детерминированный тест с намеренным расщеплением двухбайтовой кириллической буквы `п` по границе чанков, доказывающий устойчивость `Buffer.concat`.
