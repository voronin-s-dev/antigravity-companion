## Что произошло хронологически

1. В коммите `dad5ac5` агент добавил тест жизненного цикла супервизора `test/supervisor_lifecycle.test.js`.
2. Функция `testPowerShellScriptsAst()` выполняла `child_process.execSync('powershell ...')` для проверки синтаксиса `.ps1` файлов.
3. Локальный запуск `npm test` на машине разработчика (Windows) завершился успешно (все 8 сьютов зеленые).
4. Агент создал тег `v1.7.5`, запушил изменения в GitHub и сразу отрапортовал пользователю об успехе.
5. GitHub Actions запустил workflow `CI & Release Packaging` на `ubuntu-latest`. Команда `powershell` на Linux завершилась с ошибкой `powershell: not found`, провалив шаг `validate` и отменив джоб `release`.
6. Пользователь обнаружил красный статус сборки и вызвал `/aar`.

## Исправления

1. **Кросс-платформенный guard в `test/supervisor_lifecycle.test.js`**:
   - Добавлена проверка `const isWindows = process.platform === 'win32';`.
   - На не-Windows системах (CI на Linux) вызов `powershell.exe` безопасно пропускается с информационным логом, аналогично `test/backup_manager.test.js`.
2. **Карта проверок `.claude/aar/checks-map.md`**:
   - Направление `U` дополнено требованием кросс-платформенной изоляции системных утилит Windows.
3. **Регламент релизных проверок (`R`)**:
   - Агент обязан дождаться завершения workflow в GitHub Actions через `gh run watch` перед рапортом пользователю.
