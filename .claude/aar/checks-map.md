# Карта проверок проекта Antigravity Companion (скилл aar, шаг 6)

Направление — вид вопроса, который проверка задаёт проекту или выводу агента.
Код направления пишется в поле `угол` журнала разборов.
Колонка «Чего не ловит» главная: она показывает границы применимости.

## Направления

| Код | Направление | Где исполняется | Что ловит | Чего не ловит |
|---|---|---|---|---|
| `U` | Модульные и кросс-платформенные тесты | `npm test` (`test/run_all.js`) | Синтаксис JS, целостность словаря, утечки токенов, логику бэкапа, селекторов и кросс-платформенную изоляцию утилит Windows | Реальное поведение в Electron, доставку релиза на GitHub |
| `C` | CDP-инспекция живого окна Electron | `npm run doctor:cdp`, `node bin/cdp_doctor.js --eval` | Доступность порта отладки, рендеринг виджета в DOM Antigravity, значения стилей | Фоновые сетевые обновления, сборку ZIP-архива |
| `R` | Контроль сборки релиза, CI и доставки | GitHub Actions (`gh run list`, `release.yml`) | Зелёный статус CI validate, сборку ZIP-архива релиза, публикацию на GitHub | Ошибки в работе сторонних антивирусов на клиенте |
| `D` | Выводы по данным и состоянию проекта | `ACTIVE_STATE.md`, `git status` | Рассинхрон версий, незафиксированные правки, превышение лимита шагов | Несоответствие между веткой `main` и тегом `v*` |
| `L` | Локализация динамических токенов и кодировка | `npm test` (`testDynamicTokensLocalization`, правило 6 `testDictionaryIntegrity`) | Английские даты и единицы времени внутри regex-групп, символы `\uFFFD` в словаре | Canvas-тексты и пиксельный WebGL-рендеринг |

## Когда направление обязательно

| Что затронуто | Обязательные направления |
|---|---|
| Любая правка клиентского JS/CSS | `U` + `C` (тесты синтаксиса + CDP-проверка в окне) |
| Любой push коммита в ветку main | `U` + `R` (локальный `npm test` + проверка статуса CI через `gh run list`) |
| Правка словаря и очереди строк | `U` + `L` (`testDictionaryIntegrity`, проверка `\uFFFD`) |
| Правка regex-шаблонов и движка перевода | `U` + `L` (`testDynamicTokensLocalization`) |
| Добавление тестов с вызовом шелла или утилит ОС | `U` (обязательный guard `process.platform === 'win32'` для Linux CI) |
| Публикация исправления для пользователей | `U` + `R` (обязательное повышение версии в `package.json`, тег `v*`, проверка `releases` на GitHub) |
| Завершение сессии диалога | `D` (обновление `ACTIVE_STATE.md`, фиксация коммита) |
