# AGENTS.md — Antigravity Companion Control Plane & Orchestration Architecture

## 1. Иерархия решений и Source of Truth

Приоритет источников истины:
1. **Прямые инструкции пользователя** в текущем диалоге.
2. **`AGENTS.md`** (Главный операционный регламент, границы ролей и протокол субагентов).
3. **`ACTIVE_STATE.md`** (Компактный рабочий срез текущего состояния проекта).
4. **`GEMINI.md` / `BLUEPRINT.md`** (Проектные соглашения и архитектура).
5. **Локальные автоматические тесты** (`test/syntax_injection.test.js`, `test/dictionary_integrity.test.js`).
6. **Суждение агента**.

## 2. Маршрутизация контекста (Minimum Sufficient Context)

Строго запрещено загружать файлы целиком при решении узких задач. Загружайте **только то, что материально необходимо**:

| Тип задачи | Разрешённый минимальный контекст | Запрещено читать |
| :--- | :--- | :--- |
| **Добавление переводов** | `localization/untranslated_queue.json`, `localization/translations_to_merge.json` | ❌ `localization/dictionary_ru.json` целиком |
| **Правка виджета лимитов** | Фрагменты строк `limits_widget/inject_panel.js` по диапазону (`StartLine`/`EndLine`) | ❌ Весь `inject_panel.js` (2000+ строк) целиком |
| **Логика движка локализации** | Фрагменты `localization/translation_engine.js` по диапазону | ❌ Внедиапазонные строки и словарь |
| **CDP-инспекция DOM** | Вызов `node bin/cdp_doctor.js --eval "..."` через CLI | ❌ Создание scratch-скриптов WebSocket |
| **История проекта** | `ACTIVE_STATE.md` (до 100 строк) | ❌ `docs/MILESTONES_HISTORY.md` (Cold Archive) |

* **Правило Cold Archive**: Файлы в `docs/MILESTONES_HISTORY.md` и архивах являются холодным хранилищем. Их **запрещено** читать автоматически при старте сессии или выполнении рядовых задач.

## 3. Архитектура «Оркестратор + Эфемерные субагенты» (FM Pattern)

Главный агент в сессии действует строго как **Оркестратор**:

1. **Запрет на монолитные действия в главном чате**:
   - Главный агент **не должен** выполнять многошаговые черновые операции (массовый сбор строк, длинные тестовые прогоны, подбор селекторов методом проб и ошибок) в основном контексте.
   - Это предотвращает накопление сотен тысяч токенов логов и устраняет риск взрывного $O(N^2)$ роста контекста.
2. **Автоматический конвейер через субагентов**:
   `USER → ORCHESTRATOR → invoke_subagent(ROLE) → 3-строчный результат → USER`.
3. **Эфемерный контекст**:
   - Контекст субагента изолирован. Все его черновые шаги, полные дампы вывода команд и промежуточные ошибки **уничтожаются** при его завершении.
   - Оркестратор получает только лаконичный статус (2–4 строки).

### Специализированные роли субагентов:

* **`Translator / Harvester Subagent`**:
  - **Задача**: запуск `npm run harvest`, чтение непереведенных строк из `untranslated_queue.json`, генерация `translations_to_merge.json`, вызов `npm run merge`, проверка целостности `npm test`.
  - **Возврат**: краткий отчёт (`[OK] Добавлено 15 терминов, тесты пройдены, hot-reload применён`).
* **`CDP Verifier / Inspector Subagent`**:
  - **Задача**: проверка доступности инъекции через `npm run doctor:cdp`, вычисление DOM-селекторов и стилей через `node bin/cdp_doctor.js --eval "..."`.
  - **Возврат**: статус `PASS/FAIL` и точные вычисленные метрики.
* **`Widget & Engine Engineer Subagent`**:
  - **Задача**: точечные модификации JS/CSS в `limits_widget/inject_panel.js` или `localization/translation_engine.js`, запуск тестов синтаксиса `test/syntax_injection.test.js`, вызов `npm run reload`.
  - **Возврат**: краткое описание измененных селекторов/строк и статус прохождения тестов.

## 4. Лимиты и дисциплина инструментов (Fail-Fast Tool Budget)

1. **Жёсткий бюджет тулов (10–12 вызовов на субагента)**:
   - Любой субагент имеет лимит: максимум **10–12 вызовов инструментов**.
   - Если задача не решена за 10 шагов — **запрещено циклиться, гадать или пытаться обойти проблему костылями**. Субагент немедленно завершает работу со статусом `BLOCKED` и передаёт точную диагностическую ошибку Оркестратору.
2. **Сессионный потолок Оркестратора (30–35 ходов)**:
   - Сессия главного агента **не должна превышать 30–35 ходов**.
   - При приближении к 30 ходам Оркестратор фиксирует состояние в `ACTIVE_STATE.md`, делает Git-коммит и рекомендует пользователю чистый `/handoff`.
3. **Дисциплина компактного вывода CLI (Silent CLI)**:
   - Все тестовые и вспомогательные команды должны возвращать минимальный вывод (exit code, 1–2 строки статуса).
   - Запрещено выводить в консоль полные дампы JSON, HTML или трассировки стека при успешных операциях.
4. **Правило нулевого поллинга (Zero Polling Rule)**:
   - Никогда не опрашивать задачи через `manage_task(status)` или `schedule` в цикле.
   - Система Antigravity автоматически выполняет реактивный вейкап (wakeup) по завершении фоновой команды. После запуска команды нужно просто завершить ход без лишних вызовов.

## 5. Долгосрочная память и сохранение запаса контекста (Headroom Discipline)

* **Принцип**: **PREVENT LARGE CONTEXT > COMPRESS LARGE CONTEXT** (Предотвратить раздувание контекста важнее, чем пытаться его сжать).
* **agentmemory (`http://localhost:3111`)**: Опциональный вторичный уровень долгосрочной памяти. Используется по требованию для сохранения межсессионных архитектурных инсайтов (`memory_save`, `memory_recall`). Отсутствие или недоступность службы `agentmemory` не блокирует работу над проектом: основным источником непрерывности являются локальные файлы репозитория (`AGENTS.md`, `ACTIVE_STATE.md`).
