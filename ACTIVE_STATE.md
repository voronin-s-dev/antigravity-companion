## 2. Что уже полностью реализовано и протестировано
1. **Русификация UI**:
   - Словарь `localization/dictionary_ru.json`: **845 точных терминов**, **65 атрибутов**, **37 шаблонов** (всего свыше 945 правил перевода).
   - Полностью переведены все выпадающие списки (dropdowns/selects), радио-кнопки и переключатели во всех разделах Настроек Antigravity:
     - «Пресет безопасности» (Security preset): `Default`, `Custom`, `Turbo mode`, `Full machine`, `Vetted (Preview)` и все подробные описания рисков.
     - «Политика проверки артефактов» (Artifact Review Policy): `Всегда спрашивать` (`Always Ask`), `Всегда продолжать` (`Always Proceed`), `Запрашивать подтверждение` (`Request Review`), `Требовать подтверждения` (`Require Review`), `Выполнять в песочнице` (`Proceed in Sandbox`) и их развернутые описания.
     - «Политика выполнения JavaScript в браузере» (Browser Javascript Execution Policy): `Отключено` (`Disabled`), `Запрашивать подтверждение` (`Request Review`), `Всегда продолжать` (`Always Proceed`) и описания действий.
     - Подменю пользовательских разрешений: доступ к файлам вне проекта (`Разрешить`, `Запретить`, `Всегда спрашивать`), автовыполнение команд терминала, режим песочницы.
     - Настройки внешнего вида и табуляции: `Во весь экран` (`Fill`), `Медленно` (`Slow`), `Высокая` (`Strong`), `Наследовать из редактора` (`Inherit Editor`), `Системная`, `Светлая`, `Тёмная`.
     - Все заголовки секций и вкладок: «Доступ к файлам рабочей области», «Доступ к выполнению команд», «Доступ к сети», «Серверы MCP», «Пользовательские агенты», «Хуки», «Политики GitHub», «Настройки разрешений».
   - **Динамические всплывающие подсказки (Tooltips)**:
     - Проведен реверс-инжиниринг системы тултипов Antigravity (Base UI / react-tooltip) и обнаружен центральный реестр React Tooltip Context (`Ts.Provider` / `GJa`).
     - Переведены все ключевые тултипы главного окна: селектор модели («Выбрать модель Ctrl+/»), плашка и меню окружения («Локально», «Выбрать рабочее дерево», «Запуск в текущей рабочей области», «Новое рабочее дерево»), кнопка голосового набора («Записать аудио Ctrl+M»), кнопка отправки/отмены («Отправить сообщение», «В очередь сообщений», «Отправить сразу», «Отмена (Ctrl+D)»), кнопка «Установить IDE» («Установите Antigravity IDE для запуска и редактирования скриптов рабочей области.»).
     - Переведены тултипы управления чатом и сессиями: закрепление/открепление, архивация, создание ветки диалога (Fork), откат до точки (Undo), предупреждения о сжатии контекста (Compaction), управление панелями, поиск и др.
     - Инструмент сбора строк `localization/strings_harvester.js` (`npm run harvest`) доработан для автоматического сканирования реестра тултипов в памяти React Fiber, исключая пропуски в будущем.
2. **Виджет лимитов**:
   - Мониторинг квот Gemini и Claude.
   - Компактная «пилюля» с настраиваемыми чекбоксами (5ч и недельные).
   - Адаптивная якорная система позиционирования (`anchorX: 'left'|'right'`, `anchorY: 'top'|'bottom'`): виджет не улетает и не смещается при изменении размера окна или масштабировании (Zoom / DPI).
   - Автоматический клампинг к границам экрана (`clampToViewport`) при ресайзе, зуме и разворачивании панели.
   - Живой тикающий тултип с обратным отсчетом секунд (`#agy-limits-tooltip`).
   - Палитра цвета с экранной пипеткой (`EyeDropper`).
   - Исправлен баг анимации кнопки «Обновить» (hover-бокс неподвижен).
   - Интеграция в левый сайдбар Antigravity: кнопка «Лимиты моделей» рядом с Настройками со статусной точкой и бейджем `Alt+L`.
   - Горячая клавиша `Alt + L` (поддерживает русскую и английскую раскладки) работает в фазе capture на `window` и `document`, не блокируясь редактором и полями ввода.
   - Кнопка закрытия `✕` на виджете мягко скрывает виджет и обновляет статус в сайдбаре без разрушения DOM.
3. **Автономность и дистрибутив**:
   - Надежный запуск и автозагрузка Windows: `bin/start_silent.ps1`, `start.bat` и автозагрузочный ярлык без использования устаревшего VBScript.
   - Защита от пробелов в пути («c:\Antigravity projects\...») при запуске Node.js в фоновом режиме.
   - Центр обновлений `update_dictionary.bat` с оффлайн-заморозкой (`.lock_updates`).
   - Быстрый статус `bin/status.bat`.
4. **Звуковые оповещения о сбросе лимитов (Audio Alerts) и пользовательские звуки**:
   - Синтез звуков на Web Audio API (100% автономно, без внешних файлов и сетевых запросов) как стандартный пресет.
   - Поддержка установки **собственных звуковых сигналов** (MP3, WAV, OGG) отдельно для 5-часовых и недельных квот с загрузкой файлов прямо из интерфейса виджета.
   - Автономное хранение аудио в `localStorage` в формате Base64 Data URL с контролем размера (до 2 МБ) и кнопкой быстрого сброса на стандартный сигнал (✕).
   - Раздельные сигналы для 5-часовых (мягкий двухтональный перезвон D5->A5) и недельных (торжественное 4-нотное мажорное арпеджио C5->E5->G5->C6) лимитов.
   - Независимые чекбоксы включения/отключения в настройках (⚙️) виджета с сохранением в `localStorage` (`agy_sound_5h`, `agy_sound_weekly`).
   - Кнопки предпрослушивания («🔔 Тест» / «🎉 Тест») для каждого типа сигнала прямо в настройках (воспроизводят пользовательский файл, если он загружен, либо синтезированный сигнал).
   - Запоминание открытого состояния настроек (`agy_limits_settings_open`).
   - Интеллектуальный детектор сброса в `updateLimits()`: отслеживает переход квоты из состояния `< 100%` в `100%` с защитой от ложных срабатываний при первичном запуске (`prevBucketFractions !== null`).
5. **Глобальный голосовой ввод поверх всех окон (Global Voice Dictation Widget)**:
   - Автономный микросервер `voice_widget/voice_bridge.js` на порту `127.0.0.1:9228`, интегрированный в основной демон `bin/antigravity_companion.js`.
   - Использование движка Google Speech / Gemini Audio из Antigravity без сторонних платных API и без тяжелых зависимостей.
   - Плавающий виджет `voice_widget/floating_mic.ps1` со стилем `WS_EX_NOACTIVATE` (клик не отбирает фокус ввода у активного приложения: Telegram, браузер, Word, блокнот).
   - Глобальный хоткей Windows `Win + Shift + V` (с резервом на `Ctrl + Alt + V`).
   - Автоматическая вставка надиктованного текста через эмуляцию `Ctrl + V` с сохранением и восстановлением буфера обмена пользователя.
   - Автоматическая плавная очистка строки ввода в Antigravity, чтобы текущий рабочий чат не засорялся текстом диктовки.
   - Удобные команды запуска: `npm run voice`, `bin/voice_start.bat`.
6. **Инженерия проекта**:
   - `package.json` с проверками `npm test`, `npm start`, `npm run reload` (перевод + виджет), `npm run harvest`, `npm run merge`, `npm run doctor:cdp`, `npm run voice`, `npm run build:zip`.
   - Проектные правила `GEMINI.md` и портативный скилл `.agents/skills/antigravity-companion/`.
7. **Комплексная оптимизация токенов и лимитов (Token Economy System)**:
   - Проведен глубокий аудит транскриптов: ранние 4 сессии потребили суммарно **~257 млн токенов** (99.85% входной контекст из-за монолитных сессий на 600–700 шагов).
   - Создан экспресс-инструмент `bin/cdp_doctor.js` (`npm run doctor:cdp`) с поддержкой флага `--eval "..."` для мгновенной инспекции DOM из CLI за 1 секунду без создания scratch-скриптов.
   - Создан скрипт автоматического слияния `localization/merge_translations.js` (`npm run merge`), позволяющий добавлять новые переводы через компактный `translations_to_merge.json` без чтения 66 КБ словаря в контекст LLM.
   - Создан и установлен глобальный скилл `token-budget-guard` (`C:\Users\voron\.gemini\config\skills\token-budget-guard\SKILL.md`).
   - Закреплено правило «Сессионного потолка» (Session Ceiling — максимум 40 шагов с принудительным Handoff) и делегирование черновой работы в `invoke_subagent`.

## 5. Памятка новому агенту (Критично для лимитов!)
- **Сессионный потолок 40 шагов**: не веди бесконечные сессии. При приближении к 35–40 шагам фиксируй прогресс в `ACTIVE_STATE.md` и передавай эстафету в новую сессию через `/handoff`.
- **НЕ читай `dictionary_ru.json` целиком** (он весит 66 КБ, это сжигает 22 000 токенов за один запрос!).
- Для добавления переводов используй `npm run merge` через `translations_to_merge.json`.
- Для проверки DOM окна Antigravity используй `npm run doctor:cdp` или `node bin/cdp_doctor.js --eval "..."`, а не создавай временные WebSocket-скрипты.
- Для сложной отладки вызывай изолированных субагентов через `invoke_subagent`.
