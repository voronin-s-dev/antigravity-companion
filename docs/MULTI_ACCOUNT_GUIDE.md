# Руководство: Бесшовная работа с нескольких аккаунтов Antigravity

Если вы используете несколько платных аккаунтов Antigravity для обхода лимитов и квот моделей, данный проект полностью адаптирован для мгновенного переключения без потери контекста, архитектуры и наработок.

---

## ⚡ Единая команда для нового аккаунта (Quick Resume)

Когда вы переключили аккаунт и открыли проект `c:\Antigravity projects\antigravity-companion` в новом диалоге, просто отправьте агенту фразу:

```text
/resume
```

или

```text
Подхвати проект: прочитай ACTIVE_STATE.md и скажи, над чем мы работаем дальше.
```

### Что сделает новый агент за 3 секунды:
1. **Мгновенно прочитает [ACTIVE_STATE.md](file:///c:/Antigravity%20projects/antigravity-companion/ACTIVE_STATE.md)**: узнает текущую версию, последний коммит, все решенные задачи, текущий фокус и открытые вопросы.
2. **Подтянет архитектуру из [BLUEPRINT.md](file:///c:/Antigravity%20projects/antigravity-companion/BLUEPRINT.md)**: поймет логику CDP-инъекции, неинвазивность и запреты на чтение тяжелого словаря.
3. **Автоматически получит проектный скилл и правила**: файлы `.agents/skills/antigravity-companion/` и `GEMINI.md` загружаются самой платформой Antigravity без дополнительных настроек.
4. **Не сожжет лишние токены**: агент не будет перечитывать сотни файлов проекта заново.

## 🛠️ Самодиагностика окружения (`doctor`)

Если вы открыли проект на новом компьютере или в новой учетной записи ОС, агент (или вы лично в терминале) может запустить команду проверки:

```bash
npm run doctor
```

Она автоматически проверит:
- Наличие Node.js и Git.
- Авторизацию в GitHub CLI (`gh auth status`).
- Целостность JSON-словаря (`npm test`).
- Запущен ли процесс Antigravity и открыт ли порт CDP.
- Активность фоновой службы-компаньона и автозапуск Windows.

## 🔄 Сценарий переключения при исчерпании лимитов

### Шаг 1 (В текущем аккаунте перед выходом):
Если вы близки к исчерпанию лимита сообщений, просто напишите агенту:
> *«Зафиксируй текущее состояние в ACTIVE_STATE.md и сделай коммит»*

Агент запишет точный статус, прогресс и закоммитит изменения.

### Шаг 2 (Переключение аккаунта):
1. В левом нижнем углу Antigravity переключите профиль / выйдите и войдите под вторым аккаунтом.
2. Откройте проект `antigravity-companion`.
3. Введите `/resume`.

### Шаг 3 (Если работа ведется на РАЗНЫХ компьютерах):
- На ПК 1 перед уходом:
  ```powershell
  git push origin main
  ```
- На ПК 2 при открытии проекта:
  ```powershell
  git pull origin main
  ```
  Затем введите агенту `/resume`.

## 📦 Нужны ли внешние MCP серверы?

**Нет.** Проект спроектирован по принципу максимальной автономности:
- Управление версиями, релизы и пуши ведутся через встроенный **Git** и **GitHub CLI (`gh`)**.
- Управление переводом и виджетом осуществляется через локальный портативный скилл `.agents/skills/antigravity-companion/`.
- Такой подход бережет лимиты подписки и оставляет максимальный контекст для реального решения задач.
